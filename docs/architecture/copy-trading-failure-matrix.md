# 跟单系统故障模型与验证矩阵

## 不变量

1. 未持久化提交声明前绝不调用下单接口。
2. 同一 `signal_id` 最多对应一个确定性 `newClientOrderId`。
3. 任何无法确定“是否成交”的情况都不得盲目重下，只能查询原客户端订单号。
4. 带单员之间只共享交易所聚合仓位，不共享虚拟归属账本。
5. 首次选择只建立历史基线，不回放已有操作。
6. 不明确的方向、数量、价格、身份或接口契约全部失败关闭。
7. 风险异常只阻止增加风险；合法减仓保持可用，紧急线触发全部减仓。
8. 正式盘端点和激活入口必须显式选择 `PRODUCTION`，并由独立凭据、独立新数据库和短时效授权共同锁定；测试盘配置不能隐式切换。
